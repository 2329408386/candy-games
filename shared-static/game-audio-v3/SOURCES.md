# 压缩包音效来源

全部音频来自用户提供的 kxxxlyx_mp3.zip，文件字节保持原样，无重新编码或声音合成。
manifest.json 记录原文件名、上线文件名、大小和 SHA-256。

- GameSceneBGM.mp3：本局循环背景音乐。
- 音效6 / effect-6.mp3：点击按钮和选择答案。
- 音效3 / effect-3.mp3：答对。
- 音效5 / effect-5.mp3：连续答对2—4题。
- 音效8 / effect-8.mp3：连续答对5题及以上。
- 音效1 / effect-1.mp3：答错。
- 音效2 / effect-2.mp3：高连击额外欢呼，间隔至少3秒。
- 音效4、7：保留原素材，本次不触发。
