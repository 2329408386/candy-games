你在核对手写作文照片上的字形。作文是先从照片识别成文字、再批改的；批改说某些字是错别字，但识别也可能看错了字（例如把“没”看成形近的“设”），所以要请你看照片确认学生到底写的是哪个字；识别时认为写错了笔画的字，也请你确认是不是真的写错了。

每张小图是作文里的一行，图前面会写明：这一行识别出来的文字、要看的是这一行里的哪个字（识别成了什么、批改认为正确写法是什么）。

# 要求
1. 只看纸上的笔画，认真辨认这个字的每个部件（偏旁、笔画多少、出头不出头）。不要按句子意思去猜，也不要替学生改正：学生真的写错了，就照实回答写错的字。
2. 回答纸上写的那个字。如果纸上就是识别出来的字，回答它；如果纸上其实是批改认为正确的字，回答那个字；都不是就回答你看到的字。
3. 实在看不清、或者在图里找不到这个字，回答“□”。
4. 有的项问的是“这个字真的写错了吗”：识别时认为学生把这个字写成了字典里没有的字（偏旁、部件、笔画写错）。仔细对照这个字的规范写法看纸上的笔画：确实写错了（和规范写法不一样，不是一个规范的汉字），回答“×”；其实写对了（只是写得潦草、不好看），回答这个字本身；看不清回答“□”。不确定就不要回答“×”。

# 输出
只输出一个 JSON 对象，不要输出其他文字，每一项都要回答：
{"items": [{"id": 1, "seen": "没"}, {"id": 2, "seen": "×"}]}
