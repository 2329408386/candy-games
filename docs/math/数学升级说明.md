# 数学小游戏升级

- 数学首页：http://39.106.16.99/math/；管理后台：/math/admin。
- 保持数学自己的数据库、管理员、math_session Cookie，语文服务不作修改。
- 五个游戏各100题，按题型均衡抽题，每人20题，同局双方不重复。
- 题目依据用户提供的《北师大版三年级上册数学.md》知识点总结自编，不声称为教材原题。逐题答案、来源和解析见《数学500题复核清单.md》。
- 口算维持1000以内加减法；方向题包含不同地图和观察朝向。
- 量长度：单单位30题、厘米＋毫米30题、分米＋厘米20题、分米＋毫米20题，各类均衡覆盖零起点及非零起点。每局每人分别6、6、4、4题。
- 复合长度必须填写全部数字框；数字键盘操作当前选中的框。厘米＋毫米的小单位栏为0—9，分米＋厘米为0—9，分米＋毫米为0—99；按规范复名数判分，前导零不影响结果。
- 提交后查看解析，手动点击下一题；答对10分，连对额外5分，答错扣5分且最低0分。
- 默认每局150秒，可在各游戏开始页右上角设置30—1800秒；本局开始后时长固定。设置保存在 math-pk-settings-v1，不与语文混用。
- 使用用户提供的压缩包原音频，背景音乐为 GameSceneBGM.mp3。点击6、答对3、连击2—4题5、连击5题起8、答错1、高连击欢呼2。没有合成音频或合成人声回退。
- 授权最小单位为一个年级／学期的一个组，一码可授权多个组。游戏移动后，权限随目标组变化；打开的游戏会通过定期会话检查同步权限。
- 原三年级上册授权转换为A组，五个游戏初始均在A组。保留所有原码、设备绑定、备注、状态、设备上限、历史批次和管理员；迁移幂等，不生成替代授权码。
- 后台支持分组创建、改名、排序、同学期移动游戏，以及按组生成、编辑、查询、导出授权。有游戏、授权或历史批次引用的组禁止删除。

## 本地验证

```sh
node tests/test_banks.cjs
python tests/test_app.py
python tests/test_groups.py
python tests/run_temp_server.py
# 另开终端启动 /math 前缀代理，再运行浏览器验证（需要 Playwright）
node tests/prefix_proxy.cjs
node tests/browser_upgrade.cjs
```

以上后端和浏览器测试均使用隔离数据，不消耗正式授权设备名额。升级部署前对正式数据库执行隔离副本迁移检查，正式迁移期间只短暂停止数学服务。
