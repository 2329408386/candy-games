# 标点PK：课内原句与独立课外例句100题

课内50题全部为指定教材的连续原文片段，文字、标点与提示语位置不改写；课外50题独立自编，不套用课文对话扩写。
优先短原句，少量课内原句保留到约30—40个汉字。每局每人课内、课外各10题，7题在前、6题在中、7题在后，双方题目不重复且均为59根横线。
不在横线、操作提示或读屏标签中显示每格所需标点数量；保留逐个点选、删除和未完成不扣分。
