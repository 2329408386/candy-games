# 小学语文（统编版）各册习作与写话

布置作文时「从课本选」用的数据，由 `tools/units.py` 生成 `sites/teacher/data/units.json`。
每个单元四项：主题、文体（可以多个，用「、」隔开，取自 写人、记事、写景、状物、想象、看图写话、日记、书信、读后感；不填就是不指定）、引言（学生能看到，照教材的口吻引出这次习作）、习作重点（老师和批改看的要点，编号写）。
一年级没有单独的写话栏目。二、三年级新版教材（2025 秋起）个别单元的习作顺序有调整，老师选好以后可以再改。

## 二年级上册

### 第四单元
主题：我喜爱的玩具
文体：状物、看图写话
引言：你有哪些玩具？其中最喜欢哪一个？它是什么样子的？你是怎么和它一起玩的？先和同学说一说，再写下来。
习作重点：
1. 写清楚是什么：能说出玩具的名字，写出它的颜色、形状等样子，哪怕只抓住一两点也可以。
2. 写出怎么玩、为什么喜欢：能写一写自己怎样玩它，说出喜欢它的原因。
3. 句子完整通顺：每句话意思完整，句末加上句号、问号或感叹号。
4. 书写格式：一段话开头空两格，字写端正，标点占一格。

### 第六单元
主题：学写留言条
文体：
引言：有时候要告诉别人一件事，可对方不在，这时可以写一张留言条。想一想：你要留言给谁？有什么事？
习作重点：
1. 格式正确：第一行顶格写称呼，正文另起一行空两格，最后写上自己的名字和时间。
2. 事情说清楚：让对方一看就明白是什么事、什么时候、要做什么。
3. 语气有礼貌：用上“请”“谢谢”等礼貌用语。
4. 句子简短通顺，没有错别字。

### 第七单元
主题：看图写故事
文体：看图写话、想象
引言：图上的小老鼠在做什么？电脑屏幕上突然出现了谁？接下来会发生什么呢？发挥你的想象，把故事写下来。
习作重点：
1. 看懂图意：写清楚图上有谁、在什么地方、在做什么。
2. 合理想象：能想象人物说的话、心里想的事和故事后来怎样，故事要有开头和结尾。
3. 语句连贯：几句话之间能连起来，可以用上“一天”“突然”“最后”等词。
4. 标点和书写：会用逗号、句号、问号、感叹号，开头空两格。

## 二年级下册

### 第二单元
主题：我的好朋友
文体：写人、看图写话
引言：你的好朋友是谁？他长什么样？你们经常一起做什么？写一写你的好朋友，让大家也认识他。
习作重点：
1. 写出样子：抓住好朋友外貌上的一两个特点来写，不必面面俱到。
2. 写出一起做的事：至少写一件你们一起做过的事，写清楚在哪里、做了什么。
3. 表达感情：能写出自己喜欢这个朋友的心情。
4. 句子通顺，标点正确，开头空两格。

### 第四单元
主题：看图写故事
文体：看图写话、想象
引言：小青虫、蚂蚁和蝴蝶找到了几个鸡蛋壳，它们会用鸡蛋壳做什么呢？仔细看图，按顺序把它们一天的经历写下来。
习作重点：
1. 按顺序写：能按图的顺序写，用上“早上”“过了一会儿”“到了下午”“天黑了”等表示时间的词把几幅图连起来。
2. 看清每幅图：写清楚每幅图上的小动物在做什么。
3. 加入想象：可以想象小动物们说的话和心情，让故事更有趣。
4. 语句连贯通顺，标点正确。

### 第六单元
主题：我的“问号”卡片
文体：
引言：大自然里有许许多多的奥秘。你对什么感到好奇？把你心中的“问号”写在卡片上，和小伙伴交换看看吧。
习作重点：
1. 问题清楚：能用完整的句子提出问题，句末用问号。
2. 有自己的观察：最好写一写自己是在什么时候、看到什么才想到这个问题的。
3. 可以试着写写自己的猜想，不要求一定写出正确答案。
4. 书写工整，没有错别字。

### 第七单元
主题：我想养小动物
文体：状物、看图写话
引言：如果可以养一只小动物，你想养什么？为什么想养它？试着多写几条理由，说服爸爸妈妈吧。
习作重点：
1. 说清想养什么：写出小动物的名字，可以写写它的样子或习性。
2. 理由充分：能写出两条或两条以上的理由，理由要和这种小动物有关。
3. 句子连贯：可以用“因为”“而且”“还”等词把理由连起来。
4. 标点正确，开头空两格，书写工整。

## 三年级上册

### 第一单元
主题：猜猜他是谁
文体：写人
引言：选一位同学，不写出他的名字，写一写他的样子、性格或者爱好，让大家读了以后猜一猜他是谁。
习作重点：
1. 抓住特点：选择一两点最有辨识度的特点来写，比如外貌上的特别之处、性格或爱好，让人一读就能猜出是谁。
2. 用事例说明：写性格、爱好时，能用一件小事来证明，而不是只说“他很热心”。
3. 语句通顺：句子完整，意思清楚，不写重复啰嗦的话。
4. 格式规范：段落开头空两格，标点符号使用正确。

### 第二单元
主题：写日记
文体：日记
引言：日记可以记下每天的所见所闻所感。今天有什么让你开心、难过或者觉得新鲜的事？把它写成一篇日记吧。
习作重点：
1. 格式正确：第一行写清日期、星期和天气。
2. 内容真实：写自己当天真实经历的事情或真实的想法，选一件印象最深的事来写。
3. 写清楚：把事情的经过写明白，能写出当时的心情和感受。
4. 语句通顺，标点正确，没有错别字。

### 第三单元
主题：我来编童话
文体：想象
引言：童话的世界多奇妙啊！从教材里选一组词语，比如“西红柿、茄子 / 夏天 / 菜园”，想一想故事里有哪些角色、在什么时间什么地点、发生了什么事情，编一个童话。
习作重点：
1. 要素清楚：写清故事的角色、时间、地点和发生的事情。
2. 想象有趣：角色要像童话里那样会说会想，情节新奇又合情合理。
3. 故事完整：有开头、经过和结尾，经过部分写具体。
4. 自拟题目并居中，学着用修改符号改正错别字和不通顺的句子。

### 第四单元
主题：续写故事
文体：想象、记事
引言：李晓明的爸爸妈妈在外地工作，他的生日快到了，同学们正在悄悄商量……看懂图中的故事，想一想接下来会发生什么，把故事写完。
习作重点：
1. 承接情境：续写的内容要和前面的故事连得上，人物、事情前后一致。
2. 想象合理：后面发生的事要合情合理，能写出人物的语言、动作和心情。
3. 情节完整：故事要有结果，结尾自然。
4. 语句通顺，标点正确，对话要用上引号。

### 第五单元
主题：我们眼中的缤纷世界
文体：写人、写景、状物
引言：这段时间我们观察了不少身边的事物，有了很多新发现。这次习作，就让我们把最近观察时印象最深的一种事物或一处场景写下来。
习作重点：
1. 观察的准确性：看学生是否能够对选择的事物或场景进行准确且全面的观察，包括颜色、形状、大小等方面，要尽可能覆盖细节。如果描述模糊或大致概述，可能无法真实反映其观察能力。
2. 描述的详细程度：期待看到学生将观察到的事物或场景以具体、精细的语言描述出来。用词生动有趣，并试图通过文字让读者感受到他所描绘的世界。详细描写可以使读者感同身受，形成清晰的画面感。
3. 文笔流畅与创新性：文章是否通顺易读，并注重语句和段落间过渡的自然与协调。同时在描述过程中尝试适当使用一些新颖、别致但恰到好处的比喻或象征，增添文章文采。
4. 个人情感的参与和诉说：通过描述的事物或场景投射出自己的情感是否饱满，心情变化是否细腻。可以适当描绘自己在望见所描写对象时内心的变化，如快乐、好奇、感动等，使作文更加生动且含有独特意味。

### 第六单元
主题：这儿真美
文体：写景
引言：我们身边有许多美丽的地方：公园的一角、小区的花坛、学校的操场……选一处你觉得美的地方，仔细观察，把它介绍给大家。
习作重点：
1. 围绕一个意思写：能用一句话写出这个地方总的特点，再围绕这句话一句一句写具体。
2. 观察细致：写出有哪些景物、它们是什么样子的，可以写颜色、形状、声音、气味。
3. 运用积累：尝试用上本学期新学的词语和比喻、拟人等写法，让景物更生动。
4. 表达喜爱：字里行间能看出对这个地方的喜爱；句子通顺、意思清楚。

### 第七单元
主题：我有一个想法
文体：
引言：生活中有不少让人觉得不方便、不合理的现象，比如上学路上的拥堵、教室里的浪费……你注意到了什么？对此有什么想法？写下来，说不定能帮大家解决问题。
习作重点：
1. 现象写清楚：写明发现了什么问题，在哪里、是什么样子。
2. 想法明确：清楚地说出自己的看法，最好能说明理由。
3. 有改进办法：能提出切实可行的建议或解决办法。
4. 条理清楚：按“现象—想法—建议”的顺序写，语句通顺，读的人能明白。

### 第八单元
主题：那次经历真难忘
文体：记事
引言：生活中总有一些经历让人难以忘记，也许是一次旅行、一次比赛，也许是一次意外。回忆一下，把那次经历写下来，和大家分享你的心情。
习作重点：
1. 经过完整：写清楚时间、地点、人物和事情的起因、经过、结果。
2. 重点具体：把最难忘的部分写详细，写出当时看到的、听到的、想到的。
3. 表达心情：能写出“难忘”的原因和自己真实的感受。
4. 标点正确：注意引号、冒号、感叹号的用法，语句通顺。

## 三年级下册

### 第一单元
主题：我的植物朋友
文体：状物
引言：你有没有一种喜欢的植物？走近它，看一看、摸一摸、闻一闻，做一张记录卡，然后借助记录卡把你的植物朋友介绍给大家。
习作重点：
1. 观察仔细：能从样子（颜色、形状、大小）、气味、摸上去的感觉等方面写出植物的特点。
2. 写清楚：按一定顺序写，比如从整体到部分、从下到上，让读者能想象出它的样子。
3. 写出感受：能写出自己观察时的发现和对这种植物的喜爱。
4. 语句通顺，用词准确，可以用上比喻让描写更生动。

### 第二单元
主题：看图画，写一写
文体：看图写话、记事
引言：春天来了，孩子们在草地上放风筝。仔细看图，图上有哪些人？他们在干什么？动作怎样？想象他们可能会说些什么，把看到的、想到的写下来。
习作重点：
1. 看清画面：写清楚有哪些人、在哪里、在做什么，介绍要有顺序。
2. 写出动作：抓住人物的动作把放风筝的过程写具体。
3. 合理想象：能想象人物的语言和心情，让画面“活”起来。
4. 没有错别字，语句通顺，标点正确。

### 第三单元
主题：我做了一项小实验
文体：记事
引言：你做过哪些有趣的小实验？比如“鸡蛋浮起来”“纸杯烧开水”。想一想实验的名称、准备了什么、怎么做的、结果怎样，把它写下来。
习作重点：
1. 过程清楚：用上“先……接着……然后……最后……”等词语，把实验步骤按顺序写明白。
2. 要素齐全：写清实验名称、准备的材料、过程和结果。
3. 写出发现：能写出实验时的心情和有趣的发现，以及想到的问题。
4. 用词准确：动作词用得恰当，语句通顺。

### 第五单元
主题：奇妙的想象
文体：想象
引言：贪玩的小水滴、躲在草丛里的星星、假如人类可以冬眠……从这些题目里选一个，或者另起一个题目，大胆想象，创造你自己的想象世界。
习作重点：
1. 想象大胆新奇：写出与众不同的想象，让人读了觉得有趣。
2. 想象合理：故事中的事情前后连得上，符合角色的特点。
3. 内容具体：把最奇妙的部分写详细，写出角色的语言、动作和心情。
4. 故事完整，语句通顺，标点正确。

### 第六单元
主题：身边那些有特点的人
文体：写人
引言：“热心肠”“智多星”“小书虫”……读到这些词语，你会想到身边的谁？选一个人，写写他的特点，再给习作取一个能体现人物特点的题目。
习作重点：
1. 特点鲜明：抓住人物最突出的一个特点来写，题目能体现这个特点。
2. 事例具体：用一两件具体的事来表现这个特点，写出人物的动作、语言。
3. 选材恰当：所写的事能证明人物的特点，不跑题。
4. 语句通顺，没有错别字，标点正确。

### 第七单元
主题：国宝大熊猫
文体：状物
引言：大熊猫是我们的国宝，大家对它有许多好奇的问题：它吃什么？它为什么是黑白色的？围绕这些问题查查资料，向别人介绍大熊猫。
习作重点：
1. 内容准确：介绍的内容要真实可靠，可以结合查到的资料。
2. 有条理：围绕几个问题分几个方面介绍，一个方面写一段。
3. 写出特点：写出大熊猫的样子、吃的东西、生活习性等特点。
4. 用修改符号修改：检查内容是否准确、语句是否通顺、标点是否正确。

### 第八单元
主题：这样想象真有趣
文体：想象
引言：如果老鹰不会飞了，如果蜗牛跑得飞快……选一种动物作主角，想一想它失去原来的特点或变得完全相反以后，会发生什么奇异的事，编一个童话。
习作重点：
1. 想象有趣：动物的变化要新奇，变化后的生活要写得有趣。
2. 情节合理：围绕“变化”展开，前因后果能连起来。
3. 写清楚：把动物变化后遇到的事情写具体，写出它的感受。
4. 故事完整，语句通顺，学着用修改符号修改。

## 四年级上册

### 第一单元
主题：推荐一个好地方
文体：写景
引言：你去过哪些好玩的地方？公园、书店、小吃街、乡下的果园……选一个你最想推荐的地方，写清楚它在哪里、有什么特别之处，让大家都想去看看。
习作重点：
1. 写清地点：交代这个地方在哪里、是什么地方。
2. 突出特别之处：抓住最吸引人的地方写，把推荐理由写充分、写具体。
3. 条理清楚：理由较多时可以分段写，每段讲一个方面。
4. 有吸引力：语言生动，能激发读者去看看的兴趣。

### 第二单元
主题：小小“动物园”
文体：写人
引言：如果把家看作一个“动物园”，你家里的人分别像什么动物？爸爸像勤劳的牛，妹妹像爱唱歌的小鸟……想一想，写一写你的家人。
习作重点：
1. 比得恰当：家人和动物之间要有相似的地方，比如性格、外貌或习惯。
2. 用事例表现：通过具体的事情写出家人像这种动物的地方，而不是只说“他像……”。
3. 写出感情：能写出家人的可爱和自己对家人的爱。
4. 语句通顺，用词准确，读起来有趣。

### 第三单元
主题：写观察日记
文体：日记、状物
引言：你一定观察过什么吧：豆子发芽、蚕宝宝长大、月亮的变化……选一个对象连续观察几天，把观察到的变化用日记记录下来。
习作重点：
1. 格式正确：每篇写清日期、天气，按时间顺序记录。
2. 写出变化：重点写观察对象一天天的变化，写出不同时候的样子。
3. 观察细致：运用多种感官观察，用准确的词语描写，可以用上比喻。
4. 写出想法：记录观察时的心情、疑问和发现。

### 第四单元
主题：我和____过一天
文体：想象
引言：如果可以和一位神话或童话故事里的人物一起过一天，你会选谁？你们会去哪里、做什么、发生什么故事？补全题目，写下这奇妙的一天。
习作重点：
1. 人物鲜明：故事中的人物要符合他原来在故事里的特点和本领。
2. 想象丰富：写清楚去哪里、做什么，情节新奇有趣。
3. 重点突出：把最有意思的一两件事写具体，写出对话和动作。
4. 故事完整，语句通顺，书写工整。

### 第五单元
主题：生活万花筒
文体：记事
引言：生活就像万花筒，每天都有新鲜事发生：捉蚊趣事、一件烦心事、教室里的掌声……从你亲身经历、看到或听说的事情里，选一件印象最深的事写下来。
习作重点：
1. 顺序清楚：按一定顺序写，写清事情的起因、经过、结果。
2. 经过具体：把事情的经过写详细，写出人物的动作、语言、神态。
3. 选材有意义：所选的事情真实、印象深刻。
4. 能写出自己的感受，语句通顺，标点正确。

### 第六单元
主题：记一次游戏
文体：记事

3. 感情真挚：通过细节描写表达对这个人的感激、喜爱之情。
4. 首尾呼应，语句通顺。

## 六年级下册

### 第一单元
主题：家乡的风俗
文体：记事
引言：每个地方都有自己独特的风俗：春节贴春联、端午赛龙舟、中秋赏月……介绍一种家乡的风俗，或者写一写你参加风俗活动的经历。
习作重点：
1. 抓住特点：写清这种风俗的特点和习俗。
2. 详略得当：介绍风俗时重点突出，写经历时把印象深的部分写具体。
3. 写出感受：能写出风俗的意义和自己的感受。
4. 内容准确，可以查资料或问长辈。

### 第二单元
主题：写作品梗概
文体：
引言：读了一本好书，怎样用简短的文字介绍它的主要内容呢？选一本你读过的书，写一写它的梗概。
习作重点：
1. 理清框架：先理清书的基本框架，把握要点。
2. 简明概括：保留主要内容，删去枝节，用简明的语言叙述。
3. 连贯完整：把各章节的概括连成一篇，必要时补充过渡。
4. 语言简洁，条理清楚。

### 第三单元
主题：让真情自然流露
文体：记事
引言：快乐、伤心、感动、懊悔……选一种你印象最深的感受，回想引起这种感受的事情，把真情自然地流露出来。
习作重点：
1. 选择感受：选一种真实的、印象最深的感受。
2. 事情具体：把引起感受的事情写清楚，重点部分写具体。
3. 真情流露：把感情融入叙述和描写中，自然流露，不空喊口号。
4. 语句通顺，有真情实感。

### 第四单元
主题：心愿
文体：记事
引言：每个人心中都有一个美好的心愿：希望奶奶身体健康，希望环境更美好……选择恰当的方式，写一写你的心愿。
习作重点：
1. 心愿明确：写清自己的心愿是什么。
2. 写出原因：结合具体事例写出为什么有这个心愿。
3. 方式恰当：可以写一件事，也可以写书信、日记、诗歌等。
4. 感情真挚，语句通顺。

### 第五单元
主题：插上科学的翅膀飞
文体：想象
引言：在未来的世界里，科学技术会带给人们什么样的奇妙经历？大胆设想，写一个科幻故事，把读者带进神奇的科幻世界。
习作重点：
1. 科学性：故事中的科技虽是虚构，但要有一定的科学依据，令人信服。
2. 想象丰富：设想人物的生活环境和奇特经历。
3. 情节完整：故事有开头、发展、高潮、结尾。
4. 语言生动，题目新颖。
