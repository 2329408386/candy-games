## 逐题清单

- P001：《望洞庭》的作者是谁？ 选项：王维 / 李白 / 杜牧 / 刘禹锡 答案：**刘禹锡**
  - 解析：《望洞庭》是唐代诗人刘禹锡写的。　来源：知诗人 · 《望洞庭》
- P002：《山行》的作者是（ ）。 选项：杜牧 / 叶绍翁 / 刘禹锡 / 苏轼 答案：**杜牧**
  - 解析：《山行》是唐代诗人杜牧写的。　来源：知诗人 · 《山行》
- P003：《夜书所见》的作者是（ ）。 选项：杜牧 / 王昌龄 / 袁枚 / 叶绍翁 答案：**叶绍翁**
  - 解析：《夜书所见》是宋代诗人叶绍翁写的。　来源：知诗人 · 《夜书所见》
- P004：《鹿柴》的作者是（ ）。 选项：王昌龄 / 李白 / 王维 / 刘禹锡 答案：**王维**
  - 解析：《鹿柴》是唐代诗人王维写的，王维曾在鹿柴隐居。　来源：知诗人 · 《鹿柴》
- P005：《望天门山》的作者是（ ）。 选项：杜牧 / 苏轼 / 王维 / 李白 答案：**李白**
  - 解析：《望天门山》是唐代诗人李白写的。　来源：知诗人 · 《望天门山》
- P006：《饮湖上初晴后雨》的作者是（ ）。 选项：李白 / 袁枚 / 叶绍翁 / 苏轼 答案：**苏轼**
  - 解析：《饮湖上初晴后雨》是宋代诗人苏轼写的。　来源：知诗人 · 《饮湖上初晴后雨》
- P007：《所见》的作者是（ ）。 选项：袁枚 / 杜牧 / 叶绍翁 / 王维 答案：**袁枚**
  - 解析：《所见》是清代诗人袁枚写的；名字相近的《夜书所见》是叶绍翁写的。　来源：知诗人 · 《所见》
- P008：《早发白帝城》的作者是（ ）。 选项：刘禹锡 / 王维 / 杜牧 / 李白 答案：**李白**
  - 解析：《早发白帝城》是唐代诗人李白写的。　来源：知诗人 · 《早发白帝城》
- P009：《采莲曲》的作者是（ ）。 选项：袁枚 / 李白 / 王维 / 王昌龄 答案：**王昌龄**
  - 解析：《采莲曲》是唐代诗人王昌龄写的。　来源：知诗人 · 《采莲曲》
- P010：《夜书所见》的作者叶绍翁是哪个朝代的诗人？ 选项：唐代 / 宋代 / 清代 / 汉代 答案：**宋代**
  - 解析：叶绍翁是宋代诗人。　来源：知诗人 · 《夜书所见》
- P011：《所见》的作者袁枚是哪个朝代的诗人？ 选项：清代 / 明代 / 宋代 / 唐代 答案：**清代**
  - 解析：袁枚是清代诗人。　来源：知诗人 · 《所见》
- P012：苏轼是哪个朝代的诗人？ 选项：清代 / 宋代 / 唐代 / 元代 答案：**宋代**
  - 解析：苏轼是宋代诗人，本学期学过他的《饮湖上初晴后雨》。　来源：知诗人 · 《饮湖上初晴后雨》
- P013：下面哪一组诗都是李白写的？ 选项：《望天门山》《早发白帝城》 / 《早发白帝城》《山行》 / 《望天门山》《鹿柴》 / 《望洞庭》《采莲曲》 答案：**《望天门山》《早发白帝城》**
  - 解析：《望天门山》《早发白帝城》都是李白写的；《鹿柴》是王维、《山行》是杜牧、《望洞庭》是刘禹锡、《采莲曲》是王昌龄写的。　来源：知诗人 · 《望天门山》
- P014：本学期学过的下面几首诗中，哪一首是宋代的？ 选项：《夜书所见》 / 《鹿柴》 / 《山行》 / 《望洞庭》 答案：**《夜书所见》**
  - 解析：《夜书所见》是宋代叶绍翁写的，其余三首都是唐诗。　来源：知诗人 · 《夜书所见》
- P015：下面哪首诗不是唐代诗人写的？ 选项：《山行》 / 《采莲曲》 / 《望天门山》 / 《饮湖上初晴后雨》 答案：**《饮湖上初晴后雨》**
  - 解析：《饮湖上初晴后雨》的作者苏轼是宋代人；王昌龄、李白、杜牧都是唐代诗人。　来源：知诗人 · 《饮湖上初晴后雨》
- P016：下列哪首诗是清代诗人写的？ 选项：《饮湖上初晴后雨》 / 《所见》 / 《夜书所见》 / 《早发白帝城》 答案：**《所见》**
  - 解析：《所见》是清代袁枚写的；《夜书所见》《饮湖上初晴后雨》是宋诗，《早发白帝城》是唐诗。　来源：知诗人 · 《所见》
- P017：“停车坐爱枫林晚”出自哪首诗？ 选项：《山行》 / 《鹿柴》 / 《望洞庭》 / 《夜书所见》 答案：**《山行》**
  - 解析：“停车坐爱枫林晚”出自杜牧的《山行》。　来源：知诗人 · 《山行》
- P018：“白银盘里一青螺”的作者是谁？ 选项：苏轼 / 刘禹锡 / 李白 / 杜牧 答案：**刘禹锡**
  - 解析：“白银盘里一青螺”出自刘禹锡的《望洞庭》。　来源：知诗人 · 《望洞庭》
- P019：“返景入深林，复照青苔上。”的作者是（ ）。 选项：王昌龄 / 王维 / 李白 / 袁枚 答案：**王维**
  - 解析：这两句出自王维的《鹿柴》。　来源：知诗人 · 《鹿柴》
- P020：“闻歌始觉有人来”出自（ ）。 选项：王昌龄《采莲曲》 / 王维《鹿柴》 / 李白《早发白帝城》 / 袁枚《所见》 答案：**王昌龄《采莲曲》**
  - 解析：“闻歌始觉有人来”出自王昌龄的《采莲曲》。　来源：知诗人 · 《采莲曲》
- P021：“意欲捕鸣蝉，忽然闭口立。”出自（ ）。 选项：王昌龄《采莲曲》 / 杜牧《山行》 / 袁枚《所见》 / 叶绍翁《夜书所见》 答案：**袁枚《所见》**
  - 解析：这两句出自袁枚的《所见》，写的是牧童想捉蝉。　来源：知诗人 · 《所见》
- P022：被人们称为“诗仙”的诗人是（ ），本学期我们学过他的《望天门山》。 选项：杜牧 / 李白 / 王维 / 苏轼 答案：**李白**
  - 解析：李白被称为“诗仙”，《望天门山》《早发白帝城》都是他写的。　来源：知诗人 · 《望天门山》
- P023：苏轼，号（ ），他在诗中把西湖比作西子。 选项：樊川居士 / 东坡居士 / 青莲居士 / 摩诘居士 答案：**东坡居士**
  - 解析：苏轼号东坡居士；青莲居士是李白，摩诘居士是王维，樊川是杜牧的别称。　来源：知诗人 · 《饮湖上初晴后雨》
- P024：《鹿柴》的作者王维被人们称为（ ）。 选项：诗圣 / 诗鬼 / 诗佛 / 诗仙 答案：**诗佛**
  - 解析：王维被称为“诗佛”；“诗仙”是李白，“诗圣”是杜甫，“诗鬼”是李贺。　来源：知诗人 · 《鹿柴》
- P025：“朝辞白帝彩云间”和“孤帆一片日边来”的作者是（ ）。 选项：分别是王维和李白 / 同一位诗人：杜牧 / 同一位诗人：李白 / 分别是李白和王维 答案：**同一位诗人：李白**
  - 解析：“朝辞白帝彩云间”出自《早发白帝城》，“孤帆一片日边来”出自《望天门山》，都是李白写的。　来源：知诗人 · 《早发白帝城》
- P026：诗题《山行》的意思是（ ）。 选项：去山里打猎 / 山在移动 / 在山上居住 / 在山中行走 答案：**在山中行走**
  - 解析：“行”是行走，《山行》就是在山中行走，诗中写的是一路上看到的景色。　来源：解诗题 · 《山行》
- P027：《夜书所见》中“书”的意思是（ ）。 选项：写 / 读书 / 书信 / 书本 答案：**写**
  - 解析：“书”在这里是动词，意思是写。　来源：解诗题 · 《夜书所见》
- P028：《夜书所见》题目的意思是（ ）。 选项：夜里梦见的事情 / 夜里看见了一本书 / 夜里读书时看到的内容 / 夜里写下看到的景物 答案：**夜里写下看到的景物**
  - 解析：“夜”是夜里，“书”是写，“所见”是看到的景物。　来源：解诗题 · 《夜书所见》
- P029：《饮湖上初晴后雨》题目的意思是（ ）。 选项：在西湖上饮酒，天气先晴后雨 / 在湖上喝水，起初下雨后来转晴 / 喝完湖水后天晴了又下雨 / 在湖边看雨，雨后天晴 答案：**在西湖上饮酒，天气先晴后雨**
  - 解析：“饮湖上”是在西湖上饮酒，“初晴后雨”是开始天晴、后来下雨。　来源：解诗题 · 《饮湖上初晴后雨》
- P030：《早发白帝城》中“发”的意思是（ ）。 选项：发现 / 出发 / 发芽 / 头发 答案：**出发**
  - 解析：“早发白帝城”就是早上从白帝城出发。　来源：解诗题 · 《早发白帝城》
- P031：《鹿柴》中的“柴”读（ ），意思是栅栏。 选项：chái / zhài / cái / zhǎi 答案：**zhài**
  - 解析：课文注释：柴，同“寨”，栅栏，这里读zhài。　来源：解诗题 · 《鹿柴》
- P032：《望天门山》中的“天门山”指的是（ ）。 选项：一座叫天门的寺庙 / 洞庭湖中的君山 / 天上的一扇门 / 隔江相对、像一座天然大门的两座山 答案：**隔江相对、像一座天然大门的两座山**
  - 解析：课文注释：天门山是东梁山与西梁山的合称，两山隔江相对，像一座天然的大门。　来源：解诗题 · 《望天门山》
- P033：《望洞庭》中的“洞庭”指的是（ ）。 选项：一个山洞 / 洞庭湖 / 西湖 / 长江 答案：**洞庭湖**

- P034：“停车坐爱枫林晚”中“坐”的意思是（ ）。 选项：座位 / 因为 / 坐下 / 乘坐 答案：**因为**
  - 解析：课文注释：坐，因为。“停车坐爱枫林晚”就是因为喜爱傍晚的枫林而停下车来。　来源：解诗题 · 《山行》
- P035：“远上寒山石径斜”中“斜”的意思是（ ）。 选项：曲折向前延伸 / 太阳西下 / 倾倒 / 歪斜不正 答案：**曲折向前延伸**

- P039：“知有儿童挑促织”中“挑”的意思是（ ）。 选项：用细长的东西拨 / 用肩膀挑担子 / 挑战 / 挑选 答案：**用细长的东西拨**
  - 解析：课文注释：挑，用细长的东西拨。　来源：解诗题 · 《夜书所见》
- P040：“知有儿童挑促织”中的“促织”指的是（ ）。 选项：织布机 / 蟋蟀 / 蝉 / 萤火虫 答案：**蟋蟀**
  - 解析：课文注释：促织，蟋蟀，也叫蛐蛐。　来源：解诗题 · 《夜书所见》
- P041：“夜深篱落一灯明”中“篱落”的意思是（ ）。 选项：落叶 / 院子 / 篱笆倒了 / 篱笆 答案：**篱笆**

  - 解析：诗人坐在船上，船向前行，两岸青山仿佛迎面而出，一个“出”字写活了青山。　来源：悟诗情 · 《望天门山》
- P088：《饮湖上初晴后雨》表达了诗人对（ ）的赞美。 选项：西湖美景 / 洞庭湖的秋月 / 西施的美貌 / 江南的雨天 答案：**西湖美景**
  - 解析：诗人把西湖比作西施，是为了赞美西湖的美景。　来源：悟诗情 · 《饮湖上初晴后雨》
- P089：“淡妆浓抹总相宜”说明西湖（ ）。 选项：只有雨天美 / 晴天雨天都很美 / 晴天雨天都不美 / 只有晴天美 答案：**晴天雨天都很美**

- P090：《早发白帝城》表达了诗人（ ）的心情。 选项：轻松愉快 / 悲伤难过 / 害怕紧张 / 思念家乡 答案：**轻松愉快**

- P091：“轻舟已过万重山”中的“轻”字，除了写船行得快，还让人感受到诗人（ ）。 选项：船上没有行李 / 身体很轻 / 很想停下来休息 / 心情轻快 答案：**心情轻快**

- P092：《所见》表现了牧童（ ）。 选项：天真活泼、充满童趣 / 悲伤孤独 / 胆小害怕 / 勤劳能干 答案：**天真活泼、充满童趣**

- P093：《所见》中牧童“忽然闭口立”，是因为（ ）。 选项：想捉鸣蝉，怕惊走了它 / 唱歌唱累了 / 被黄牛吓到了 / 听到有人喊他 答案：**想捉鸣蝉，怕惊走了它**

- P094：《采莲曲》描绘了（ ）的画面。 选项：姑娘在家中织布 / 采莲姑娘与荷花融为一体、歌声欢快 / 孩子在篱笆边捉蟋蟀 / 渔夫在江上打鱼 答案：**采莲姑娘与荷花融为一体、歌声欢快**

- P095：下列诗中，表达思乡之情的是（ ）。 选项：《夜书所见》 / 《山行》 / 《望天门山》 / 《所见》 答案：**《夜书所见》**
